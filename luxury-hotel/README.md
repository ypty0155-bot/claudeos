# Hôtel Aurelle · 澜悦酒店

这里有两个单文件作品，建筑、材质、城市、音乐和音效全部由代码实时生成，没有任何图片、模型或音频素材：

- `index.html`：一段约 2 分 36 秒的实时三维“影片”。从夜色中的前庭进入大堂、环绕一周、走到电梯、乘电梯到 38 层、出电梯、刷卡进入 3808 套房、上床熄灯入睡。
- `world.html`：“澜悦夜城”，同一家酒店和它周围的街区做成的开放世界，第一人称自由行走。

两者都需要联网：页面会从 jsDelivr 加载 three.js r147，从 Google Fonts 加载字体。

# 影片 `index.html`

用 Chrome、Edge、Safari 或 Firefox 的最新版本直接打开 `index.html`，点击“开始入住”。页面会从 jsDelivr 加载 three.js r147，从 Google Fonts 加载字体，所以需要联网。

## 技术要点

- 画面是时间轴 `t` 的纯函数：相机、门、电梯、灯光、窗帘都由 `t` 计算得出，所以可以随意暂停和拖动。
- 相机路径用带时间切线的 Hermite 样条插值位置和偏航 / 俯仰 / 滚转角；步行时叠加轻微的头部晃动，焦距也跟着关键帧变化（自动对焦）。
- 真实感渲染：
  - 屏幕空间环境光遮蔽（SSAO），让墙角、家具底部和藻井自然变暗；
  - 两盏投射软阴影的聚光灯（大堂水晶灯、门廊、套房吊顶、床头阅读灯等）；
  - 加载时为每个空间拍一张真实环境贴图，金属、玻璃、大理石反射的是它们真正所处的环境；
  - 平面实时反射：大理石地面、雨后湿漉漉的前庭和积水、套房落地窗映出房间；
  - 程序生成的法线贴图：地砖缝、人字拼木地板、胡桃木纹、地毯绒毛、布料编织、软包床头的拉扣凹陷、洞石孔洞；
  - 景深（刷卡、躺床等近景会虚化背景）、轻微色散和镜头畸变、暖色光晕、胶片颗粒。
- 生活细节：城市街道上有移动的车灯，远处楼宇的窗户偶尔熄灭；树冠由上万片叶簇组成；喷泉有水雾；鲜花是杯状花朵；羽绒被和床旗自然垂坠并带褶皱。
- 静态几何按材质合并成少量 draw call；水晶、花朵、城市楼宇、酒瓶用 InstancedMesh。
- 8 盏点光源和 2 盏阴影聚光灯组成固定光源池，按场景重新布置，避免切换场景时重新编译着色器；阴影贴图只在灯光移动或场景变化时更新。
- 帧率偏低时会自动降低渲染分辨率；控制栏的“流畅”模式会关闭环境光遮蔽、景深和实时反射。
- 音乐（钢琴与铺底和弦）和音效（喷泉、电梯提示音、刷卡提示音、门锁）全部用 Web Audio 合成。

# 开放世界 `world.html`

用桌面版 Chrome、Edge、Safari 或 Firefox 打开 `world.html`，等城市搭建完成后点击“进入夜城”。第一次加载要生成材质、建筑和 8 个空间的环境反射，普通电脑大约需要十几秒。

| 奔跑 | Shift |

| 互动 | E 或鼠标左键 |

## 四个时间

开场页和右下角的时间按钮都可以选：

- **清晨 06:12**：太阳刚从东边升起，天边是淡橘色，街上有薄雾，路灯快要熄灭。
- **正午 12:30**：蓝天白云，阳光从高处照下，楼宇在街上投下清晰的影子，路灯全关，玻璃窗映出天空。
- **黄昏 18:42**：夕阳从西边低低地照在楼面上，天空从橘红过渡到紫蓝，路灯和窗灯陆续亮起。
- **夜晚 23:08**：月光、星空和整座城市的灯火。

切换时间时会重新拍摄 8 个空间的环境反射，第一次切到某个时间要稍等一下，之后再切回来是即时的。上次选的时间会被记住。

## 可以去哪里、做什么

- **酒店前庭**：雨后反光的石材地面、三层喷泉、棕榈、门廊和红毯。喷泉、花坛和柱子都有碰撞，走到自动门前门会打开。
- **大堂**：12 米挑高的穹顶和水晶吊灯、前台、酒吧、三角钢琴；可以按前台服务铃、弹一段钢琴，大理石旋转楼梯可以真的走上夹层。
- **电梯**：在电梯厅按呼梯键，等门开后走进轿厢，面向按钮面板按 E 选 38 层。轿厢会载着你上升，到站开门后走出去。
- **38 层与 3808 套房**：在 3808 门前刷卡，指示灯变绿、门锁弹开后走进房间，灯光渐亮、窗帘自动拉开。房间里可以分别开关顶灯、两盏床头台灯、落地灯、电视和窗帘，走到床边按 E 躺下休息，再按 E 起身。
- **街区里的 12 家店**：酒店周围挑了 12 栋楼，把底层做成可以走进去的店，每家都有铜框玻璃橱窗、敞开的玻璃门、发光店招、自己的灯光和一件可以互动的事：

## 技术要点

- **窗户里的房间**：远处楼宇的每一扇窗都用 interior mapping 着色器在窗玻璃后面“画”出一个有纵深的房间（地板、天花、墙、家具剪影、窗帘、灯光颜色），视角变化时有真实的视差；底层商铺用同样的方法画出货架和灯箱。每扇窗的房间布局、是否亮灯、是否拉帘都是按实例随机的。
- **可进入的店铺**：规划地块时，从酒店附近按距离挑出互相隔开的楼，按立面的开间宽度截出几个整开间作为店面，楼体的底层体量和碰撞体都减去这块矩形，立面在这段不再生成墙基和假橱窗，留给真正的玻璃门面。书、酒瓶、商品、花朵、唱片这类成百上千的小物件用带单独颜色的实例网格绘制。
- **大量几何的绘制**：楼宇构件（檐口、壁柱、窗框、栏杆等）按材质合并成 InstancedMesh，并按 150 米的区块切分，每块有自己的包围球，不在视野里的区块直接跳过；材质贴图按世界坐标盒式投影，所以同一套砖石纹理在任何尺寸的构件上都不会被拉伸。
- **沿用影片的渲染管线**：HDR、SSAO、两盏阴影聚光灯、每个空间单独拍摄的环境反射、平面实时反射（大理石地面、积水、落地窗）、景深、光晕和胶片颗粒。
- **树、草地和路面**：行道树和花园里的树是真正的三维树：分叉的树干和枝杈，树冠由几十张带透明叶簇贴图的叶片组成，受光照、在阳光下投出斑驳的影子，叶片法线朝树冠外侧，所以有体积感，并随风轻轻摆动。草地是 1024 像素的草叶、枯草和小花纹理，再按世界坐标叠一层大尺度的色斑，看不出重复平铺。沥青按真实旧路面的反照率（约 10%）绘制，有石子颗粒、修补块、灌缝裂纹和油渍；车道线有磨损，路面上有井盖和路边雨水箅子。石材、砖和混凝土外墙在人行道以上一米左右有溅泥变暗的区域，墙面有大尺度的色斑，高处略带烟尘。手机和平板上树叶数量减半、阳光阴影贴图降一档，以保证流畅。
- **时间与阳光**：天空着色器同时包含夜空（星星、月亮、云）和白天的天空（按太阳方向变化的地平线颜色、日晕、日轮、被阳光照亮的云）。太阳是一盏跟着玩家移动的平行光，阴影贴图覆盖周围约 190 米，只在走出一定范围后才重新渲染；街区楼宇只画进太阳的阴影贴图，不进室内聚光灯的阴影，所以白天有楼影、室内也不会变慢。每个时间有自己的雾色、曝光、窗内灯光比例和玻璃反射色。
- **动态灯光**：8 盏点光源的固定光源池，每一帧挑离玩家最近、当前空间看得见的灯来点亮，远处的灯靠自发光材质和光晕表现。
- **碰撞与移动**：网格加速的方盒 / 圆柱碰撞、台阶与楼梯高度函数、跟随轿厢的站立平面、奔跑时的头部晃动和脚步声（按地面材质切换石材、大理石、地毯、木地板）。
- **空间与声音**：按玩家位置判断所在空间（前庭、大堂、电梯、走廊、套房、咖啡馆、街道），切换环境反射、曝光和声音层：城市底噪、喷泉、室内钢琴、电梯提示音、刷卡声、门锁声都用 Web Audio 合成。
- 帧率偏低时自动降低渲染分辨率。
