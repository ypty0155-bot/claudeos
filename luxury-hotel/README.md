# Hôtel Aurelle · 澜悦酒店

一段约 2 分 36 秒的实时三维“影片”：从夜色中的前庭进入大堂、环绕一周、走到电梯、乘电梯到 38 层、出电梯、刷卡进入 3808 套房、上床熄灯入睡。

整个场景只有一个文件 `index.html`。建筑、大理石、水晶灯、城市、音乐和音效全部由代码实时生成，没有任何图片、模型或音频素材。

## 打开方式

用 Chrome、Edge、Safari 或 Firefox 的最新版本直接打开 `index.html`，点击“开始入住”。页面会从 jsDelivr 加载 three.js r147，从 Google Fonts 加载字体，所以需要联网。

| 操作 | 按键 |
| --- | --- |
| 播放 / 暂停 | 空格 |
| 快退 / 快进 5 秒 | ← / → |
| 静音 | M |
| 全屏 | F |

底部时间轴可以拖动，按章节分段显示。

## 技术要点

- 画面是时间轴 `t` 的纯函数：相机、门、电梯、灯光、窗帘都由 `t` 计算得出，所以可以随意暂停和拖动。
- 相机路径用带时间切线的 Hermite 样条插值位置和偏航 / 俯仰 / 滚转角；步行时叠加轻微的头部晃动，焦距也跟着关键帧变化（自动对焦）。
- 真实感渲染：
  - 屏幕空间环境光遮蔽（SSAO），让墙角、家具底部和藻井自然变暗；
  - 两盏投射软阴影的聚光灯（大堂水晶灯、门廊、套房吊顶、床头阅读灯等）；
  - 加载时为每个空间拍一张真实环境贴图，金属、玻璃、大理石反射的是它们真正所处的环境；
  - 平面实时反射：大理石地面、雨后湿漉漉的前庭和积水、套房落地窗映出房间；
  - 程序生成的法线贴图：地砖缝、人字拼木地板、胡桃木纹、地毯绒毛、布料编织、软包床头的拉扣凹陷、洞石孔洞；
  - 景深（刷卡、躺床等近景会虚化背景）、轻微色散和镜头畸变、暖色光晕、胶片颗粒。
- 生活细节：城市街道上有移动的车灯，远处楼宇的窗户偶尔熄灭；树冠由上万片叶簇组成；喷泉有水雾；鲜花是杯状花朵；羽绒被和床旗自然垂坠并带褶皱。
- 静态几何按材质合并成少量 draw call；水晶、花朵、城市楼宇、酒瓶用 InstancedMesh。
- 8 盏点光源和 2 盏阴影聚光灯组成固定光源池，按场景重新布置，避免切换场景时重新编译着色器；阴影贴图只在灯光移动或场景变化时更新。
- 帧率偏低时会自动降低渲染分辨率；控制栏的“流畅”模式会关闭环境光遮蔽、景深和实时反射。
- 音乐（钢琴与铺底和弦）和音效（喷泉、电梯提示音、刷卡提示音、门锁）全部用 Web Audio 合成。
