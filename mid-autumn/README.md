# 小饼如嚼月

一个中秋主题的单页网页：用 three.js 实时建模一枚广式月饼，以七道工序为线索讲中秋。

| 工序 | 模型变化 | 讲的内容 |
| --- | --- | --- |
| 壹 · 取月为心 | 湖上的月亮飞落，变成咸蛋黄 | 中秋之名、祭月 |
| 贰 · 以馅裹月 | 馅料溶解式显形，可切换四种馅 | 南北六派月饼 |
| 叁 · 薄皮合拢 | 饼皮由下往上包住馅心 | 饼皮配比、月饼史 |
| 肆 · 入模压花 | 木模压下，十六瓣花边和“花好月圆”阳文成形 | 月宫三则 |
| 伍 · 入炉烘烤 | 饼皮由白转金，炉温计时同步 | 火候与回油 |
| 陆 · 一饼四分 | 切成四块，露出蛋黄切面，每块一个字 | 团圆 |
| 柒 · 举头望月 | 月亮重新升起，孔明灯与桂花 | 各地风俗，可玩的厦门博饼 |

## 打开方式

直接用浏览器打开 `index.html` 即可，需要联网加载 three.js（jsDelivr）和 Google Fonts。

## 实现要点

- 月饼是参数化网格：同一组 (u, θ) 参数同时描述“面团球”和“压好的月饼”，入模时在顶点着色器里插值。
- 饼面纹样来自 Canvas 绘制的高度图（花边、十六瓣花、双线圈、“花好月圆”），逐顶点采样成浮雕。
- 月饼由四块扇形拼成，切开时露出的切面由着色器按截面坐标画出饼皮、馅和蛋黄。
- 月面贴图按真实月海经纬度逐像素生成；湖面用多组正弦波法线反射月光。
- 滚动位置映射为连续的“故事进度”，镜头、动画与标注都由它驱动；左右拖动可以转动月饼。
- 饼面法线由高度图逐像素计算，凹槽做了遮蔽，侧面叠加细噪声模拟面皮质感；蛋液与蛋黄油光用清漆层（clearcoat）表现。
- 自写的后期管线：半浮点离屏渲染 + 四级高斯柔光、青暗暖亮的调色、暗角与细颗粒；环境反射由 PMREM 从一个简化的夜空场景生成。
- 顶栏“声”按钮可打开音效：Karplus–Strong 合成的古筝拨弦（D 调五声音阶）、卷积混响和很轻的湖水声，默认关闭。
