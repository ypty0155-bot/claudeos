# 盛世华诞 · 国庆短片

庆祝中华人民共和国成立 77 周年、歌颂中国共产党的国庆短片，全长 1 分 28 秒。画面、音乐和音效全部由代码生成，没有使用任何图片、视频或音频素材。

- `national-day-2026.mp4`：渲染好的成片，1920×1080，30 帧/秒，H.264 视频 + AAC 立体声，可以直接播放和转发。
- `index.html`：影片本体。用浏览器打开就能实时播放，时间轴可以拖动。
- `render.cjs`：把 `index.html` 逐帧渲染成 MP4 的脚本。

## 音乐

配乐是原创的，没有使用国歌或其他现成曲目。调式为 D 宫五声调式，速度每分钟 96 拍，每一章都正好落在小节线上。

- 红船启航：笛子独奏主题、铺底和弦、湖水声。
- 开国大典：定音鼓滚奏引出铜管号角，旗帜升到顶端时乐句收束。
- 改革开放：古筝琶音配轻快的鼓点，复兴号经过时呼啸声从右耳移到左耳。
- 逐梦星辰：钟琴琶音、弦乐长音，火箭点火时有低频轰鸣。
- 锦绣山河：弦乐与笛子齐奏抒情旋律，每小节开头一段古筝刮奏。
- 盛世华诞：大鼓、锣、镲和铜管全奏。每一朵烟花的升空哨音、爆炸声和噼啪声，都按它在画面中的时间和位置合成（左右声像跟随烟花位置）。

## 在浏览器里播放

用 Chrome、Edge、Safari 或 Firefox 的最新版本打开 `index.html`，点击“开始播放”。页面会从 Google Fonts 加载思源宋体（Noto Serif SC）和马善政毛笔楷书（Ma Shan Zheng），所以需要联网。

## 重新渲染视频

需要 Node.js、Playwright（带 Chromium），以及带 libx264 的 ffmpeg：

```sh
npm install playwright
FFMPEG=/path/to/ffmpeg node render.cjs national-day-2026.mp4
```

| 参数 | 作用 |
| --- | --- |
| `--fps 30` | 帧率 |
| `--workers 3` | 同时渲染的页面数，按 CPU 核数调整 |
| `--pcm audio.pcm` | 使用已经渲染好的原声（48 kHz、16 位立体声 PCM），跳过音频渲染 |
| `--fonts-via-curl` | 用 curl 下载 Google Fonts 再交给页面，适用于 Chromium 不信任代理证书的环境 |

脚本以 `index.html?render` 打开页面。这个模式下页面会隐藏播放界面，并暴露 `window.film`：`frame(t)` 画出第 t 秒的画面，`audio()` 用 OfflineAudioContext 渲染整段原声。视频帧分给几个页面并行渲染成若干段 H.264，最后拼接，并混入原声（整体增益调到约 -15 LUFS，并用限幅器把峰值压在 -1 dBFS 以下，保留配乐由弱到强的起伏）。

## 技术要点

- 画面是时间轴 `t` 的纯函数：船的起伏、旗帜飘动、楼宇生长、火箭轨迹、烟花粒子都由 `t` 直接算出，所以可以随意暂停、拖动，也可以逐帧导出。
- 用 Canvas 2D 绘制。红船、天安门（朝霞和夜景两套配色）、华表、火箭、天宫空间站和陆家嘴地标都先画进离屏画布，再逐帧组合。
- 五星红旗按国家标准绘制：旗面长宽比 3:2，大星位于左上方，四颗小星各有一个角正对大星中心。飘动效果是把旗面切成 100 条竖条分别错位，再叠加明暗。
- 烟花粒子的位置是带空气阻力和重力的运动方程的解析解，拖动时间轴时不需要逐帧模拟；有牡丹、菊花、圆环、五角星、垂柳、噼啪六种形态。
- 江面倒影逐行复制已画好的天际线并加上波纹位移；湖面上的红船倒影也是同样的做法。
- 音色全部由 Web Audio 合成：锯齿波弦乐和铜管、正弦加三角波的笛子（带颤音和倚音）、三角波古筝、非谐波的钟琴和锣、噪声合成的鼓与烟花，经过卷积混响和压缩器输出。实时播放和导出视频用的是同一份乐谱。
- 后期效果：泛光、暗角、胶片颗粒、章节角标，以及章节之间的交叉淡化。
