# 盛世华诞 · 2026 国庆献礼短片

`national_day_2026.mp4`：60 秒、1280×720、30fps 的国庆短片，歌颂中国共产党、庆祝中华人民共和国成立 77 周年。画面、烟花、五星红旗飘动、长城日出、配乐和音效全部由 `make_video.py` 用代码生成，没有使用任何图片、视频或音频素材；配乐是原创的五声音阶旋律。

| 时间 | 场景 |
| --- | --- |
| 0–7 秒 | 夜空烟花与城市天际线，“1949—2026 热烈庆祝中华人民共和国成立77周年” |
| 7–15 秒 | 五星红旗迎着朝阳飘扬，“山河锦绣 国泰民安” |
| 15–35 秒 | 百年征程时间轴：1921 建党、1949 开国、1964 原子弹、1978 改革开放、1997 香港回归、2008 北京奥运、2021 全面小康、2026 “十五五”开局 |
| 35–47 秒 | 长城日出：“没有共产党 就没有新中国”“不忘初心 牢记使命”“为中国人民谋幸福 为中华民族谋复兴” |
| 47–60 秒 | 烟花满天、万家灯火：“祝福伟大祖国 繁荣昌盛”“国庆快乐 2026·10·1” |

## 重新生成

```bash
pip install pillow numpy imageio-ffmpeg
python make_video.py                  # 约 3 分钟，输出 national_day_2026.mp4
python make_video.py --preview 18 53  # 只导出指定秒数的静帧，便于调试
```

需要系统里有文泉驿正黑字体（`/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`），可在脚本顶部的 `FONT` 修改路径。
