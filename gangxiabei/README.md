# 岗厦北站台 · 深圳地铁 B2 层

`index.html` 是深圳地铁岗厦北枢纽 **B2 站台层**的实时三维模型：11 号线与 14 号线同台换乘的两座岛式站台、四股道、全高屏蔽门、扶梯和楼梯、导向标识、乘客信息屏，以及按时刻表进站、开门、关门、离站的列车和上下车、换乘的乘客。单个 HTML 文件，结构、材质、列车、文字标识、人物和声音全部由代码生成，没有图片、模型或音频素材。

页面从 jsDelivr 加载 three.js r147，从 Google Fonts 加载 Noto Sans SC 和 Barlow Semi Condensed，所以需要联网。

## 打开方式

用最新版 Chrome、Edge、Safari 或 Firefox 直接打开 `index.html`，点“进入站台”（同时打开声音）。

| 操作 | 按键 |
| --- | --- |
| 行走 | W A S D / 方向键，按住 Shift 快走 |
| 转头 | 拖动画面 |
| 焦距 | 滚轮 / 双指捏合 |
| 预设视角 | 1 – 9，或点左下角 |
| 南岛 ⇄ 北岛 | Tab |
| 行走 / 环绕 | V（环绕模式下拖动旋转，右键或双指平移，滚轮缩放） |
| 剖视（揭开吊顶） | C |
| 声音 | M |
| 时间快进 1× / 4× | T |

手机和平板上左下角是移动摇杆，拖动画面转头。

## 按公开资料还原的部分

- **双岛四线**：B2 层是 11、14 号线站台层，两座岛式站台各宽 16 米；中间两股道是 14 号线，南、北外侧是 11 号线。
- **同台同向换乘**：2024 年 11 月 9 日起两线在岗厦北同台换乘，11 号线启用双向站台。模型按右侧行车排布：南岛是 11 号线终到（自福田方向）⇄ 14 号线开往沙田，北岛是 14 号线终到（自黄木岗方向）⇄ 11 号线开往碧头。下车的乘客约六成走到对面排队换乘，其余去扶梯出站。
- **列车**：两线都是 8 节编组 A 型车（本模型全长 185.6 米，宽 3 米，每侧 5 对塞拉门）。14 号线为明黄色涂装、全自动运行；11 号线为紫红色涂装。车顶有空调机组，第 2、7 节车有受电弓，搭在刚性架空接触网（汇流排）上。
- **线路色与站名**：2 号线橙、10 号线粉、11 号线紫红、14 号线黄；屏蔽门上方的线路图按实际站序绘制，14 号线岗厦北—沙田 18 站，11 号线岗厦北—碧头 19 站。
- **深圳之眼**：B1 站厅中央的圆形采光天窗（直径约 9 米）和按费马螺旋排布的天花，从扶梯开口可以看到，按 9 进入 B1 近看。

## 依据常见做法复原的部分

公开资料里没有 B2 层的装修图，所以下面这些是按深圳地铁新线的常见做法设计的，并非施工图：拱形白色铝格栅吊顶和线形灯带、白色圆柱和站名环、灰色花岗岩地面与黄色盲道、候车地标、导向牌的内容和位置、乘客信息屏的版式、墙面灯箱（只用公益和线路宣传画，不含商业广告）、扶梯和电梯的位置、B1 站厅的布置，以及 150 秒一班的压缩时刻表（真实行车间隔更长）。

## 技术要点

- **结构**：静态几何按材质合并成少量网格；轨枕、扣件、柱子、屏蔽门门扇、扶梯踏板、乘客都用实例化网格。
- **列车**：车体按 A 型车断面轮廓拉伸，门洞和车窗带按车门位置切分；车头把同一断面沿车长放样、收窄、后掠而成，风挡、头灯、尾灯按放样位置分区着色。每列车一组几何，开关门只更新实例矩阵。
- **时刻表**：每股道一个周期函数，给出进站（匀速后匀减速停在站台正中）、停站（开门、关门预告、关门）和出站（匀加速）的位置与状态；屏蔽门、门头灯、乘客信息屏、右上角列车动态和广播都从同一个状态读取。
- **乘客**：约 170 个实例化人物（躯干、双腿、头、头发、背包各一个实例网格），会排队候车、先下后上、同台换乘、坐长椅、乘扶梯上下；腿部按步伐摆动。
- **画面**：花岗岩地面有实时平面反射（半分辨率、按粗糙度模糊），整站用站内拍摄的环境贴图做反射；吊顶灯带用矩形面光源照明，另有屏幕空间环境光遮蔽、光晕、ACES 色调映射和轻微颗粒。帧率偏低时自动降低渲染分辨率；手机和平板关闭地面反射和环境光遮蔽、减少光源和人数。
- **声音**：隧道底噪、列车进出站的轮轨声和电机声、制动尖啸、进站“叮咚”、屏蔽门关门蜂鸣都用 Web Audio 合成；浏览器支持中文语音时会播报进站广播。
