# claudeos

- [`national-day/`](national-day/)：盛世华诞，庆祝中华人民共和国成立 77 周年、歌颂中国共产党的国庆短片（1 分 28 秒，1080p MP4），以及生成它的单个 HTML 文件。画面和原创配乐全部由代码生成：红船启航、开国大典、改革开放、逐梦星辰、锦绣山河、天安门前的烟花。
- [`luxury-hotel/`](luxury-hotel/)：Hôtel Aurelle 澜悦酒店，一段用 Three.js 实时渲染的超豪华酒店入住影片（单个 HTML 文件），以及同一家酒店和周围街区做成的第一人称开放世界 `world.html`。
