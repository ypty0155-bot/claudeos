# 山岚大奖赛 · Ridgeline

一个写实风格的实时三维赛车游戏，只有一个 HTML 文件。赛道、地形、树木、赛车、天空、引擎声全部由代码实时生成，没有任何图片、模型或音频素材。

页面需要联网：会从 jsDelivr 加载 three.js r147，从 Google Fonts 加载字体。

## 打开方式

用最新版 Chrome、Edge、Safari 或 Firefox 直接打开 `index.html`（需要支持 WebGL 2），在菜单里选好模式，点击“进入赛道”或按 Enter。菜单背后是 AI 车手正在比赛的转播画面。

| 操作 | 键盘 | 手柄 |
| --- | --- | --- |
| 油门 | W / ↑ | RT |
| 刹车（停稳后按住倒车） | S / ↓ | LT |
| 转向 | A D / ← → | 左摇杆 |
| 手刹 | 空格 | A |
| 氮气加速（按住） | Shift / N | X |
| 升档 / 降档（手动挡） | E / Q | RB / LB |
| 切换视角 | C | Y |
| 回到赛道 | R | Back |
| 暂停 | Esc / P | Start |
| 静音 | M | |

手机和平板上，左下角是左右转向键，右下角是油门和刹车，上方的“氮气”和“视角”按钮分别是氮气加速和切换视角。

菜单里可以选**转向灵敏度**（标准 / 灵敏 / 很灵敏，默认“灵敏”），也可以关掉氮气加速。

## 模式

- **大奖赛**：和 7 名 AI 车手同场，可选 2、3、5 圈，你从第 6 位发车。五盏红灯每隔 0.9 秒亮起一盏，全亮后在随机时刻同时熄灭，这一刻起跑。领跑者冲线后，其余车辆在下一次经过终点线时完赛，然后显示成绩表（总时间、与冠军的差距、每人最快圈，全场最快圈标紫色）。比赛中左上角是转播风格的实时排名和差距，发车区旁的排名塔屏幕也会同步显示。
- **计时赛**：独自上赛道，驶过起终点线后开始计时。赛道分三段，每过一个分段点都会显示与个人最快圈的时间差（绿色更快、红色更慢、紫色刷新纪录）。最快圈会保存在浏览器里，下次以半透明的“幽灵车”重放。四个车轮全部越出赛道界限，这一圈就判为无效。

## 氮气加速

按住 Shift（或 N、手柄 X、触屏“氮气”）喷射氮气：自动全油门，额外约 7 千牛推力，100→200 km/h 从约 5.6 秒缩短到约 3.2 秒，极速可以多冲到约 308 km/h。满罐可以连续喷 4.5 秒，松开后约 22 秒回满；转速表左边的蓝色竖条显示剩余量。喷射时排气管喷出蓝色火焰，镜头视野拉宽并带速度模糊。循迹控制打开时，多出的推力同样受后轮抓地力限制，所以低速弯出口猛喷会被“吃掉”一部分。AI 车手也会在前方足够长的直道上使用氮气。

## 赛道

山岚赛道全长 3.18 公里，顺时针行驶，12 个弯道，高低落差 26 米：

1. 约 600 米长的主直道，两侧分别是维修区大楼和 16 排观众看台，终点线上方是发车龙门架；
2. T1 是重刹右弯，外侧有看台、砂石缓冲区和轮胎墙；
3. 上坡的连续 S 弯穿过秋天的树林；
4. 山顶附近的下坡发夹弯，外侧是砂石缓冲区和轮胎墙；
5. 一路下坡的后直道，中段有一座广告桥；
6. 高速右弯接减速弯，最后一个右弯回到主直道。

路面有白线、红白路缘石、被轮胎磨黑的行车线和修补过的补丁。赛道外有修剪过的草地、砂石缓冲区、波形护栏、轮胎墙、混凝土墙和铁丝网、广告牌、救援哨亭。内场有一座湖，四周是约 1.2 万棵程序生成的针叶树和秋色阔叶树，远处是山。

## 车辆物理

这是一场单一车型的 GT 杯赛，八辆车只有涂装不同。每辆车（包括 AI）用同一套物理，以 360 Hz 固定步长计算：

- **轮胎**：侧向力用魔术公式曲线，纵向和侧向力由摩擦椭圆耦合，抓地力随载荷增加而变弱（载荷敏感度）。沥青、路缘石、草地、砂石的附着力和滚动阻力各不相同，开上砂石会明显减速。
- **载荷转移**：加速、刹车时前后轴载荷转移，过弯时左右转移（按前后侧倾刚度分配），坡道和路面起伏也会改变载荷。
- **空气动力**：阻力随速度平方增长；下压力让高速弯比低速弯能承受更大的侧向加速度。
- **动力总成**：5.2 升自然吸气 V8 扭矩曲线、六速序列式变速箱（自动或手动）、起步时离合器打滑、红线断油、松油门时的发动机制动。
- **刹车**：70% 前 / 30% 后的制动力分配；ABS 关掉后，刹得太狠车轮会抱死，车会推头。
- **转向**：键盘或触屏按住方向键约 0.2 秒打满，最大转向角随车速减小，但始终保留足够的角度让前轮用到抓地力峰值；三档灵敏度会整体放大或缩小转向角。
- **驾驶辅助**：ABS、循迹控制（按后轮已经用掉的侧向附着来限制驱动力）、转向辅助（车尾甩出时自动带一点反打），都可以在菜单里关闭。
- 实测数据：0–100 km/h 约 3.6 秒，0–200 km/h 约 9.2 秒，极速约 300 km/h，200–0 km/h 制动约 106 米；最大侧向加速度低速时约 1.3 g，高速时借下压力可达约 1.5 g。

车身会随加减速和过弯前后俯仰、左右侧倾，每个车轮单独跟随路缘石起伏；撞到护栏或其他车会按冲量反弹。

## AI 车手

- 用弹性带方法求出最小曲率的行车线，再在摩擦圆约束下前后两遍推算出整圈的目标速度；
- 纯追踪算法转向，车尾滑动时自动反打并收油；
- 前车挡路时选边超车或跟车减速，并排时互相让出空间；困在缓冲区时会回到赛道；
- 三档难度：业余、职业、传奇，单圈分别约 87、81、77 秒；每位车手还有各自的速度系数（约 0.96–1.0）。

## 画面

- 天空由着色器计算：随方位变化的地平线颜色、太阳光晕和程序生成的云；环境反射贴图从这片天空拍摄；
- HDR 渲染，ACES 色调映射、泛光、轻微色差、高速时的径向模糊、暗角和胶片颗粒；
- 太阳阴影跟随镜头并按阴影贴图像素对齐，不会闪烁；每辆车下面还有接触阴影；
- 高度雾：越低越浓，朝太阳方向偏暖，远山因此有空气透视；
- 赛车：带清漆的金属车漆和车队涂装（号码、赞助商、钣金缝、散热百叶）、深色镀膜玻璃、车手头盔、座椅和防滚架；高速时轮毂出现运动模糊，重刹后刹车盘发红，刹车灯点亮，收油时排气管喷火；
- 特效：轮胎烟、草地和砂石上的扬尘、擦护栏的火花、留在路面上的胎痕；
- 五种视角：追尾、远距追尾、引擎盖、驾驶舱（方向盘随转向转动、换挡指示灯）、保险杠；菜单背景和赛后用电视转播镜头。

## 声音

全部用 Web Audio 合成：V8 引擎是按四冲程循环频率（转速 ÷ 120）振荡的周期波，谐波按横置曲轴 V8 的点火顺序加权，再经过饱和和随油门变化的滤波；另外有进气声、轮胎尖叫、路噪、砂石声、风噪、路缘石震动、护栏刮擦、碰撞、换挡声、回火爆音、看台人群和发车倒计时。离你最近的两辆对手车有带多普勒效应的空间化引擎声。

## 技术要点

- 单个 HTML 文件，three.js r147 全局脚本加 EffectComposer 后期处理；
- 地形是约 12 万个顶点的非均匀网格：赛道附近每 5 米一个顶点，越往外越稀疏，一直延伸到远山；地形高度由赛道海拔的反距离加权场、分形噪声和脊状山体叠加，靠近赛道时平滑过渡到路面高度；
- 赛道查询用 4 米网格预存最近的中心线采样点，再在线段上局部搜索，物理和场景生成共用；
- 树木分两级细节：镜头附近 230 米内的区块用完整模型（90 米内才投射阴影），其余所有树按树种合并成一个低面数实例网格，每帧只需几次绘制调用；
- 帧率偏低时自动降低渲染分辨率；
- `window.__race` 提供测试钩子：暂停实时循环后按固定步长推进仿真、切换视角、让玩家车自动驾驶、读取状态。
